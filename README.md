# Titanic Survival Prediction – Data Cleaning Project

## About the Project
This project is part of my Week 1 Machine Learning and AI Internship assignment.

The project focuses on cleaning and preprocessing the Titanic dataset using Python.

## Tasks Performed
- Loaded the Titanic dataset using Pandas.
- Performed basic statistical analysis using info() and describe().
- Handled missing values using Mean, Median, and Mode imputation.
- Applied Label Encoding to the Sex column.
- Applied One-Hot Encoding to the Embarked column.
- Visualized passenger age distribution using Matplotlib and Seaborn.
- Exported the cleaned dataset into a CSV file.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Files Included
- Titanic_Project.ipynb – Complete project code and outputs.
- titanic_cleaned.csv – Cleaned dataset.
